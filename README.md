# 📊 Portafolio de Análisis de Datos y Econometría

¡Hola! Bienvenido a mi repositorio principal. Aquí documento mi recorrido en la ciencia de datos, combinando el análisis económico, la estadística matemática y la programación estructurada. 

Mi enfoque principal es resolver problemas analíticos escribiendo código limpio y fundamentado, priorizando la comprensión de los algoritmos y la eficiencia matemática por sobre la simple aplicación de herramientas.

## 🛠️ Stack Tecnológico
* **Lenguajes:** Python, SQL, LaTeX
* **Análisis y Modelado:** Pandas, NumPy, StatsModels, Scikit-Learn, SciPy
* **Visualización:** Matplotlib, Seaborn
* **Entorno y Despliegue:** Jupyter Notebooks, FastAPI, Uvicorn, Git
